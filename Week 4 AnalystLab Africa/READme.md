# 🦠 Project 1: COVID-19 Global Analytics Dashboard

## Objective

To analyze global COVID-19 trends and present meaningful insights through an interactive dashboard.

### Dataset

Johns Hopkins University CSSE COVID-19 Dataset

### Dashboard Features

- Executive Overview
- Global Trend Analysis
- Country Analysis
- Interactive Navigation
- Dynamic Filters
- Maps
- KPI Cards
- Drill-down Analysis

### KPIs

- Total Confirmed Cases
- Total Recoveries
- Total Deaths
- Countries Affected
- Recovery Rate
- Average Daily Cases
- Peak Daily New Cases
- Peak Daily Deaths

### Key Insights

- COVID-19 affected more than 200 countries and regions.
- Global cases experienced multiple waves during the reporting period.
- Recovery trends improved significantly over time.
- Interactive visuals make country comparisons easy and informative.

# 🛒 Project 2: Superstore Sales Analysis Dashboard

## Objective

To evaluate retail sales performance and provide actionable business insights using interactive dashboards.

### Dataset

Superstore Sales Dataset (2014–2017)

### Dashboard Features

- Executive Dashboard
- Sales Analysis
- Profit Analysis
- Customer Insights
- Interactive Navigation
- Maps
- KPI Cards
- Dynamic Filters

### KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Total Products
- Total Quantity
- Profit Margin
- Average Order Value

### Key Insights

- Sales increased steadily over the reporting period.
- Office Supplies recorded the highest order volume.
- Standard Class was the most frequently used shipping mode.
- Regional and customer analyses revealed valuable business trends.
