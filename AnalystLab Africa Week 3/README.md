# Week 3: SQL & Data Querying

## Project Overview
This project was completed as part of the **AnalystLab Africa Data Analytics Internship Program (Week 3)**. The objective was to develop practical SQL skills by importing, querying, and analyzing real-world datasets using Microsoft SQL Server.

## Tools Used
- Microsoft SQL Server Management Studio (SSMS)
- SQL Server
- GitHub

## Datasets
- **Chinook Database** – Music store relational database.
- **Sales Dataset** – Retail sales transactions dataset.

## SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions (SUM, AVG, COUNT, MIN, MAX)
- INNER JOIN
- LEFT JOIN
- Subqueries
- Window Functions (ROW_NUMBER, DENSE_RANK)

## Business Questions Answered

### Chinook Database
- Top spending customers
- Revenue by country
- Best-selling artists
- Most popular music genres
- Revenue trends

### Sales Dataset
- Sales trend
- Highest-value orders
- Product performance analysis

## Key Insights

### Chinook Database
- USA generated the highest revenue.
- Helena Holý was the highest-spending customer.
- Iron Maiden was the best-selling artist.
- Rock was the most popular genre.

### Sales Dataset
- Classic Cars generated the highest revenue among all product lines.
- Vintage Cars and Motorcycles ranked second and third respectively.
- Monthly sales trends highlighted business performance across multiple years.
- High-value customer orders were identified to support sales analysis.

## Learning Outcomes
This project strengthened my understanding of SQL by applying querying, data aggregation, joins, subqueries, and window functions to solve real business problems. It also improved my ability to extract actionable insights from relational databases using Microsoft SQL Server.
