## 2. Online Retail Sales Analysis

### Project Overview

This project analyzes transactional data from an online retail business to uncover customer purchasing behaviour, product performance, geographical sales distribution, and monthly sales trends. The analysis concludes with business recommendations and an interactive Power BI dashboard.

### Tools Used

- Python
- Pandas
- Matplotlib

### Key Tasks

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Business Insights
- Dashboard Development

### Key Findings

- Generated over **£8.88 million** in total revenue.
- The **United Kingdom** was the highest revenue-generating market.
- **PAPER CRAFT, LITTLE BIRDIE** was the highest-performing product.
- **November 2011** recorded the highest monthly sales.

### Deliverables

- Jupyter Notebook
- Cleaned Dataset
- Business Report
